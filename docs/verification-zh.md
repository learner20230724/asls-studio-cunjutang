## 性能样本

215 盏设为 100%，保留 4 盏故障约束，桌面自动画质、无空气光束、2 个演员：稳定采样约 **50 FPS**，529 次绘制调用。首个示例约 284 次绘制调用。加载／重建期间短时样本约 31–33 FPS，不能当作稳定运行帧率。

采用每批 32 灯的 HDR 累加，不创建 215 个原生 SpotLight；低画质不删灯。首版没有复杂阴影、精确遮挡与光度学保证。

## 重现

```sh
npm test
npm run build
npm start -- --host 127.0.0.1 --port 5179
```

浏览器脚本在 `scripts/browser-check.js`、`scripts/browser-ui-check.js`、`scripts/browser-production-check.js`，内容是供 Playwright CLI `run-code` 使用的回调，不是直接 `node` 执行的测试文件。

开发测试使用 `window.__CJT`；仅在开发构建存在。生产测试需分别运行 4179 根路径、4180 `/rehearsal` 两个静态服务器。浏览器截图和 JSON 测试结果在本机 `output/playwright/`，不进入 Git。
