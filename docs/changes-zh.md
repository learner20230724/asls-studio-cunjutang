# 教学版改动说明

基线：ASLS-org/studio develop `bd6d842fd7eb2dc27e65bcadcf3fb66b64bf2fe9`。保留上游历史、GPL-3.0、作者署名及第三方声明；上游介绍存于 `README.upstream.md`。

- 增加中文默认 / 英文切换的 Vue 教学工作台，而非漫画风格；移动端底部导航。
- `src/training/rig.mjs` 维护存菊堂模板、灯具能力、版本化扩展与校验。模板含 215 盏灯、4 个故障及 4 个教学场景。
- `src/training/engine.js` 复用上游 Show / Fixture / Group / Scene / Effect / Chase，不另建一套灯光场景协议。
- `src/training/renderer.js` 增加教学固定灯和摇头灯模型、实例化、受光材质、分批 HDR 累加、演员道具与相机控制。
- `training.version=1` 保存舞台、演员道具、练习设置、渐变时间、当前通道与来源；灯具的 `training` 保存稳定 ID、分区、编号、故障和估算说明。OFL 定义随工程嵌入，通用配置随项目提供。
- 修复上游实例容量、删除与稳定 ID、零号 Universe、Cue ID 生成、嵌入灯具定义等问题。
- 输出池替换为拒绝硬件连接的实现；旧文件输出配置不加载。移除浏览器路径的 WSC 客户端依赖与 XML 解析器。
- 默认只支持 ASLS JSON showfile；不提供 XML 导入、旧控台连接界面或 Electron 安装包。
- 舞台排数可通过距台口列表扩展；数量通过复制／删除灯具调整，分区、排、组、序号和稳定 ID 可编辑。另存模板仍采用同一 showfile 格式。
- 加入本地启动脚本、静态服务器、测试及部署说明。保留的上游自动部署工作流不在本开发分支触发；初始开发阶段未发布到用户服务器；后续上线记录见部署与验证文档。


## 0.2.1 · 2026-11-03

- 空气光束由12边透明锥面改为有限光锥内体积采样；对场景深度裁切，边缘和距离衰减，不再把锥面画成实体。
- 可见场地实体与阻挡范围共用定义，墙体、地板、侧幕的线段遮挡同时作用于体积光和表面受光；面光保留从台口照入的原目标，不改写用户保存的灯位或场景。
- “灯位分区”右侧增加“选中即亮”和0–100%亮度滑条；开启时立即应用到当前选择，后续单灯/分区选择和滑条调整可快速试灯。关闭时选灯不改亮度，不自动熄灭其他灯。
- 新偏好随工程保存，旧文件补默认关闭/70%；恢复工程不触发自动试灯。保留总控、黑场、故障和Solo约束。


## 0.2.2 · 2026-11-03 · 节能预览

- 删除持续重画与300ms界面轮询；变化合并后按需绘制，渐变/效果最多30帧调度，完成后休眠。后台停止绘制，返回显示最新状态。
- 空原生动画Worker停止计时和发消息，导入的效果/序列启用时恢复；保留暂停/续播的原逻辑时间。
- 静态场地、座椅、演员道具按材质合并；自动画质交互分辨率降低，停手0.22秒后补清晰帧；体积光低分辨率采样、8步积分，深度感知合成避免前景轮廓漏光。高画质保留12步。
- 滑条变化不再重置画布与分配帧缓冲；相机变化独立唤醒。去掉静止时误导性的0 FPS显示，改为“节能预览”。不更改灯数、工程存储和原有遮挡约束。


## 0.3.0 · 2026-11-04 · 清晰画面与舞台控制

- 移动/静止固定像素比，取消0.45倍率与停手补帧；增加多重采样抗锯齿。按灯光与遮挡状态缓存表面辐照度、光路深度和三维散射场，视角移动只重画，不重算灯光。
- 增加演员/桌椅/方台的遮挡，与墙体和幕布共同参与照明。移走道具会移走阴影。
- 右上角灯光全开/全关；左侧摇头灯快捷入口，包含方向、颜色、方向复位；两道幕独立开合、位置可编辑并保留到工程。
- 默认宽度21m。旧内置16m工程保留浏览器本地原字节备份，然后按比例扩宽；场景与通道值保留，不反复缩放自定义布局。
- 自动环绕从观众正视距离启动，可停止或手动接管；观众斜视沿用原预设计算方式。
- 删除界面和帮助中的教学/模拟免责声明、近似标记、免登录/纯模拟和本机保存状态；帮助改为具体操作说明。

## 0.4.0 — 四道布幕与完整场景编排（2026-11-05）

- 四道独立双开褶皱幕布，2.6 秒缓入缓出，可在中途反向；移除旧的固定侧幕与后方装饰条。幕布位置及遮挡跟随当前开合进度。
- 补齐剧场外围地面与稳定中性背景；首次进入采用观众正视，保留斜视及其他预设和环绕。
- 灯光与遮挡放入独立 Worker，合并过期请求；人物与幕布变换不重建舞台，不牺牲移动时像素。最终照明与同步参考一致，空闲不持续发任务。
- 页面内的饱和度/明度色板、色相滑条、色样与色值输入；画质移至全开左侧。选择数量与 Solo 移至左栏；总黑场恢复按钮仅留在总控，删除比较效果等冗余文字。
- “新增当前场景”直接添加可改名的场景，无命名弹窗；场景同时记录灯光、演员道具、幕布。站位、方向、幕布在场景切换时平滑插值；旧灯光场景兼容。
- 人物与道具支持直接鼠标/触摸拖动及选中框；移动时相机不抢手势。数字站位编辑也有平滑过渡。
- 五步新手引导可跳过、重看；七幕“开场到谢幕”案例由用户点击播放，包含启幕、相遇、蓝紫转场、交错行进、谢幕及落幕。案例加入独立分组，保留已有场景及额外人物道具，不会反复添加。

## 0.4.1 — 摇头灯编排与布景

- 删除工具栏常驻“播放案例”；仅从首次引导最后一步播放，帮助可重看引导。
- 新增独立的十二段“光影剧场 · 摇头灯与布景”：8 盏摇头灯成对交叉、反扫、扇形展开、回环和收束，青蓝、紫红、绿橙、金青等配色平滑变化。连续段落取消原本的 2 秒停顿。
- 增加会客桌、两把椅子、两座矮台，并随场景平滑换位。保留原有对象；重复进入不重复添加。
- 明确角度轨迹随完整场景保存/导入恢复，避免既有负角度单位解码影响演示；手动控制沿用用户原来的响应。旧示例及用户编辑保留。

## 0.4.2 — 恢复深色剧场与默认道具

- 去掉舞台和观众席外围的浅蓝填充，恢复低亮度中性剧场背景与深灰地面，保留座位和地面轮廓。
- 普通初始舞台直接摆放一张桌子、两把椅子、两座矮台；不需要进入演示。
- 旧内置工程只补缺少的家具数量，原对象、灯光、保存场景不变；原保存备份至 `.before-props-v1`。迁移只执行一次，之后主动删除不会刷新复生，不强制修改外部场地。

## 0.4.3 — 默认关闭空气光束与模板重置

- 页面启动忽略上次开启的雾光状态，默认关闭空气光束；手动开关保留，演示不再自动开启。
- 在“新增当前场景”左侧增加“重置为模板场景”，直接恢复预设工程和十二段有序场景，不把旧记录追加在前面。
- 重置后恢复舞台尺寸、灯具、人物道具、四幕、总控、筛选和正视镜头；初始画面有暖光且幕布打开，播放从序幕开始；刷新保持重置结果。
